# Emman Secorata · Video Portfolio

Files
- index.html : the page (do not need to edit)
- config.js  : ALL your text, links, video titles and descriptions. Edit this file to change the site.
- photo.jpg  : your profile photo
- thumbs/    : video thumbnails
- videos/    : your videos

To change the look, open config.js and set  "theme"  to one of: cinema, pop, block, classic
To play a video at full quality, upload it to Google Drive (share: Anyone with the link, Viewer)
and paste the link into that video's  "u"  value in config.js.
